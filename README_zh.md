# 土人方格游戏（pygame 第一版）

这是一个按你要求拆分好的 pygame 小项目，包含：

- `main.py`：主程序，终端列出关卡并启动游戏
- `solve.py`：最短路求解器（BFS）
- `core.py`：核心规则、绘制、关卡读写、动画辅助
- `mapedit.py`：图形化地图编辑器
- `levels/`：示例关卡目录

---

## 一、安装依赖

```bash
pip install pygame
```

---

## 二、启动方式

### 1）启动主程序

```bash
python main.py
```

程序会先在终端中列出 `levels` 目录下的所有关卡文件。

你可以：

- 输入编号：进入对应关卡
- 输入 `e`：打开地图编辑器
- 直接回车：退出程序

### 2）单独求解某个关卡

```bash
python solve.py levels/demo_easy.json
```

如果不传路径：

```bash
python solve.py
```

会自动列出 `levels` 目录并让你输入编号。

### 3）单独打开地图编辑器

```bash
python mapedit.py
```

---

## 三、游戏内操作

- `↑ ↓ ← →`：移动所有土人
- `R`：重开当前关卡
- `H`：求最短解
- `P`：自动播放最短解
- `ESC`：退出当前关卡并回到选关菜单

---

## 四、编辑器操作

### 鼠标

- 左键：绘制当前画笔
- 右键：擦除当前层内容

### 键盘

- `Tab`：切换当前编辑层（地形 / 角色 / 目标）
- `S`：保存
- `O`：打开文件列表
- `N`：修改关卡名称
- `F`：修改保存文件名
- `+ / -`：修改地图宽度
- `Shift + + / -`：修改地图高度
- `ESC`：退出编辑器；如果打开了文件列表，会先关闭文件列表

### 右侧按钮说明

- 层：地形 / 角色 / 目标
- 画笔0 / 画笔1 / 画笔2：表示当前层可写入的编号
- 新建关卡：创建 8x8 空白图
- 保存：写入当前文件名对应的 json
- 打开：显示 `levels` 目录中的关卡文件列表
- 修改关卡名 / 修改文件名：进入文本输入模式
- 宽度 / 高度 +/-：调整地图大小

## 五、JSON 关卡文件格式

示例：

```json
{
  "name": "演示关卡",
  "width": 7,
  "height": 5,
  "terrain": [[0,0,0],[1,1,1]],
  "actors": [[0,0,0],[0,1,0]],
  "goals": [[0,0,0],[0,0,1]],
  "victory_mode": "any"
}
```

含义：

- `name`：关卡名字
- `width`：地图宽度
- `height`：地图高度
- `terrain[y][x]`：地形位图
- `actors[y][x]`：角色位图
- `goals[y][x]`：目标位图
- `victory_mode`：胜利模式，当前默认 `any`

---

## 六、第一版编号定义

### 地形 `terrain`

- `0`：虚空（不能进入）
- `1`：平地（可进入）
- `2`：石头（阻挡）

### 角色 `actors`

- `0`：空
- `1`：土人

### 目标 `goals`

- `0`：空
- `1`：土人目标

---

## 七、当前版本胜利规则

当前按你这次描述实现为：

**任意一个土人到达任意一个土人目标，即可通关。**

也就是说：

- 不区分“哪个土人对应哪个目标”
- 只要有一个土人踩上目标，就算胜利

如果你后续想改成：

- 所有土人都必须到目标上；或
- 目标和角色一一对应；或
- 不同角色有不同目标；

只需要修改 `core.py` 里的 `is_victory_state()` 函数即可。

## 八、扩展建议

如果你要做第二版，推荐按下面顺序扩展：

1. 新增地形，例如：冰面、陷阱、传送门、按钮、门
2. 新增角色，例如：会滑行的角色、会推动障碍的角色
3. 新增目标规则，例如：所有角色都到目标才过关
4. 在 `core.py` 中把“角色规则”拆成角色类或规则表
5. 用图片资源替换当前的图元绘制
